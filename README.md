## 💡 ¿Qué hace?

Esta herramienta crea firmas de correo en HTML de forma local. Permite completar tus datos, elegir un estilo visual y copiar el resultado para usarlo desde Gmail en computador, Outlook u otro cliente de correo.

> Tus datos y tus imágenes se procesan en el navegador. No se envían a ningún servidor.

## ✨ Funciones principales

| | Función | Descripción |
|:--:|---|---|
| 🎨 | **Tres plantillas** | Ejecutiva, Minimal y Tarjeta. |
| 🖌️ | **Color de marca** | Personaliza la firma con el color que prefieras. |
| 📷 | **Foto y logo** | Carga y optimiza imágenes directamente en la herramienta. |
| 🔗 | **Enlaces clicleables** | Correo, teléfono, sitio web y LinkedIn. |
| 🌗 | **Vista clara u oscura** | La persona usuaria elige cómo revisar la firma. |
| 📋 | **Copiar firma** | Copia HTML enriquecido para pegarlo en el correo. |
| 💾 | **Descargar HTML** | Guarda una versión de respaldo de la firma. |
| 👤 | **Perfiles locales** | Guarda configuraciones en el navegador del equipo. |

## 🚀 Uso rápido

```text
1. Abre generador-firmas.html en tu navegador.
2. Completa tus datos de contacto.
3. Elige una plantilla y un color de marca.
4. Agrega foto o logo si lo necesitas.
5. Presiona "Copiar firma" y pégala en Gmail u Outlook.
```

## 🧩 Estructura del proyecto

```text

|-- generador-firmas.html     # Aplicación lista para usar

|-- test_ui.mjs               # Pruebas de interfaz
|-- LEEME.txt                 # Indicaciones del proyecto
`-- LICENSE                   # Licencia MIT
```

## 🧪 Pruebas

Si tienes Node.js instalado, ejecuta:

```bash
node test_firma.mjs
node test_ui.mjs
```

## 🔒 Privacidad

La aplicación funciona de forma local. Las imágenes se procesan en el dispositivo y los perfiles se guardan únicamente en el navegador donde se crean.
